# Meal-plans-lk
Curated meal-prep and kitchen links for Sri Lanka (hosted on GitHub Pages).
How Adding a New Item Works Now
Inside #mealSource, you just paste another <meal ...> block:

Put title, link, description, tag, and category on <meal ...>.

Put the step-by-step text inside <instructions>...</instructions> (line breaks inside <instructions> are preserved automatically).

Clicking the top of the card (or Guide) opens the instruction popup with a Print Instructions button that uses @media print to print only the instruction card instead of the whole site.
